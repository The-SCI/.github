# Security Policy

**The SCI SolCielo Innovacion Private Limited™** (`https://thesci.co` · `https://thesci.co.in`) takes the security of our infrastructure, compiled binaries, and client platforms seriously.

## Reporting a Vulnerability

If you discover a security vulnerability in any repository under `github.com/The-SCI` or across our production endpoints (`thesci.co`, `thesci.co.in`, `coach.thesci.co`, `deploy.thesci.co`, `social.thesci.co`), please **do not open a public GitHub issue**.

Instead, send a responsible disclosure report directly to:

- **Email:** `support@thesci.co.in`
- **Subject:** `[SECURITY] Brief summary of vulnerability`

Please include:
1. Affected repository, endpoint, or component.
2. Steps to reproduce or proof-of-concept details.
3. Potential impact assessment.

We acknowledge valid reports within **48 hours** and coordinate remediation before any public disclosure.
